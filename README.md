# Polynomials

## Leandro Vendramin

These are lecture notes giving a basic introduction to polynomials. 
They serve as a complement to several basic algebra courses at 
Vrije Universiteit Brussel, 
including [Ring and Module Theory](https://github.com/vendramin/rings) and [Galois Theory](https://github.com/vendramin/galois).

## PDF
[Here](https://github.com/vendramin/polynomials/blob/main/notes.pdf) is the PDF.

## Compiling 

- **`make`** — builds notes.pdf and dyslexic.pdf
- **`make notes`** — just buid the original file
- **`make dyslexic`** — just build the dyslexic version
- **`make clean`** — remove aux/log/idx files, keep the PDFs
